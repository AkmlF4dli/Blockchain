El Manuk Coin Ecosystem

Keamanan Aset Mutlak: Blockchain El Manuk dirancang dengan protokol validasi yang sangat ketat. Koin Anda dijamin tidak akan hilang karena sistem mewajibkan Wallet Miner, Wallet Pengirim (Sender), dan Wallet Penerima (Receipt) untuk terdaftar secara sah di dalam blockchain agar setiap proses mining atau pengiriman dapat dieksekusi. Jika salah satu dompet tidak valid, transaksi akan ditolak secara otomatis oleh sistem

Visi Kedaulatan Ekonomi: Seiring dengan optimalisasi sistem, ekosistem ini diproyeksikan akan membuka akses terhadap 19.000.000 unit koin El Manuk secara nasional. Sebuah pencapaian besar yang diharapkan mampu menyerap partisipasi publik secara luas demi masa depan digital yang lebih mapan bagi seluruh lapisan masyarakat Indonesia.

CLI Guide (CURL Commands)

Salin perintah di bawah ini untuk berinteraksi dengan node lokal Anda.

1. Jalankan Node
python application.py 5000
2. Registrasi Wallet Baru
curl -X POST http://localhost:5000/user/new -H "Content-Type: application/json" -d '{"password": "YOUR_PASSWORD"}'
3. Kirim Transaksi (Validasi 3 Dompet)
curl -X POST http://localhost:5000/transaction/new -H "Content-Type: application/json" -d '{"sender": "ADDR_SENDER", "recipient": "ADDR_RECEIPT", "amount": "1.0", "password": "YOUR_PASSWORD"}'
4. Mining (Validasi Miner)
curl -X GET http://localhost:5000/mine -H "Content-Type: application/json" -d '{"wallet": "ADDR_MINER"}'
5. Tambah Node Peer
curl -X POST http://localhost:5000/add/node -H "Content-Type: application/json" -d '{"node": "104.248.xx.xx:5000"}'
